
# PaperTrail MVP

This document outlines our initial MVP plan for PaperTrail, including the core features, user flow, and future ideas. Some features may be developed in later sprints as we adjust our priorities and project scope.

## Core Idea

PaperTrail is a platform where users can publish their own research papers and discover, browse, and read papers published by others.

## Core Features

| Feature | Description |
| --- | --- |
| Add / Publish Papers | Users can upload and publish their own research papers for others to discover and read. |
| Browse Papers | Users can explore research papers published by the community. |
| Read Papers | Users can open and read research papers directly on the platform. |
| User Authentication | Users can log in and out using their AT Protocol identity. |
| Reading Rooms | Each paper has a shared space for notes, summaries, questions, replies, and discussions. |
| Search Papers | Users can search for papers by title, author, or keywords. |
| Filter Papers | Users can filter papers by research area or category. |
| Bookmarks | Users can bookmark papers and access them through a personal saved-paper list. |
| Like Papers | Users can like papers to show appreciation or interest. |
| Paper Management | Authors can edit or delete their own published papers. |

## MVP User Flow

1. A user visits PaperTrail and logs in with their AT Protocol account.
2. The user browses published papers or searches for a specific topic.
3. The user selects a paper to view its details and read it.
4. The user can bookmark or like the paper.
5. The user opens the paper's Reading Room to see notes, questions, and discussions from other readers.
6. The user can share their own thoughts, ask questions, or reply to other users.
7. The user can publish their own research paper for others to discover and discuss.
8. The user can edit or delete their own published papers.

## MVP Success Criterion

A user can publish a research paper and have another user discover and read it. Readers can also participate in the paper's Reading Room by sharing notes, asking questions, and replying to other users. This allows researchers to share their work and discuss papers on the same platform.

## Future Features (Post-MVP)

| Feature | Description |
| --- | --- |
| Private Reading Rooms | Users can create private research groups to discuss papers with classmates or collaborators. |
| Advanced Personal Libraries | Users can organize bookmarked papers into folders, collections, or custom categories. |
| Follow Researchers | Users can follow other researchers to discover their publications and discussions. |
| Paper Annotations | Users can highlight sections of papers and attach notes or questions. |
| Research Recommendations | Users can discover relevant papers based on their interests and reading activity. |
| Researcher Profiles | Public profiles can show a user's published papers and research contributions. |
| Paper Version History | Authors can upload revised versions of papers while keeping access to earlier versions. |
